This project's name is `কাঁচা বাজার` means traditional Bangladeshi marketplace that sells fresh, perishable items like raw meat, fish, vegetables, and fruits. It is a digital bridge between traditional Bangladeshi open air marketplace and modern internet grocery ecosystems. this platform can act as an open-data price oracle and smart shopping assistant for those who are often unsure of if online grocery apps are overcharging them. 

Technology used in this project are - 

  1. Next.js.
  2. Typescript.
  3. Tailwind css.
  4. Daisy ui.
  5. Better Auth.
  6. MongoDB.

  Key features of this project-

 • *Secure Authentication Pipeline:* Includes a dedicated Sign-In page and secure premium platform tracking behaviors.
• *Categorized Commodity Directory:* Organized Category sections that allow users to effortlessly filter and browse through various types of product.  
• *Granular Price Shift Analytics:* The Product Details page calculates total inventory price shifts day-over-day (Today vs Yesterday) and uses color-coded visual indicator badges to flag market jumps.
• *Smart Cost Optimization Metrics:* Automatically scans incoming database matrices to isolate and highlight the premium pricing zone via an automated Highest Price Market Card.
• *SEO & Semantic Accessibility Optimization:* Uses modern Next.js asynchronous server data-fetching paradigms paired with structural HTML layouts to maximize crawling speed and readability.
